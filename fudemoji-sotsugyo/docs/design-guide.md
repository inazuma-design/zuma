# デザインガイド

判断基準はひとつ。**作品が主役で、それ以外は静かに。**

## 世界観

「静かな美術館 × 和紙のやさしさ × デジタル表現の鮮やかさ」。背景・文字・線は和紙と墨の落ち着いた色に留め、色の鮮やかさは作品そのものに任せる。装飾で「デジタル感」を出さない。

## 配色

| 役割 | 変数 | 値 | 使いどころ |
|---|---|---|---|
| 背景 | `--washi` | `#FDF8F2` | ページ全体 |
| マット台紙 | `--mat` | `#FFFFFF` | 作品を載せる額の内側。作品の色を正しく見せるため白 |
| 文字 | `--sumi` | `#2B2620` | 本文・見出し |
| 補助の文字 | `--sumi-soft` | `#6B6053` | 作者名・日付・注記 |
| アクセント | `--kaki` | `#A85A16` | 作品数の数字、ボタンの枠。面で塗らない |
| 文字リンク | `--kaki-text` | `#8A4712` | 小さな文字のリンク（和紙の上でコントラスト 6.6:1） |
| 強調 | `--shu` | `#B5453A` | ほぼ使わない。エラーや注意のためにとってある |
| 境界 | `--line` | `#E6DACA` | 額の縁、区切り線 |

筆文字サポート室と同じ色です。柿色は「藍」と呼ばれていたことがありますが、名前は `--kaki` に統一しました。

## 文字

- 見出し・作品名・展覧会名: **Yuji Syuku**（筆書き風）。ウェイトは 400 のみ
- 本文: **Zen Kaku Gothic New**。17px、行間 1.8
- Google Fonts が読めない環境では、ヒラギノ明朝／ヒラギノ角ゴ、游明朝／游ゴシック、Noto に落ちる
- `lang="ja"`、`line-break: strict`（句読点が行頭に来ない）、`font-feature-settings: "palt"`、対応ブラウザでは `word-break: auto-phrase`
- 斜体は使わない。強調は太字か文章で
- 最小サイズ: 本文 15px、注記 13px

## レイアウト

- スマホ基準（375px）。コンテンツ幅の上限 1120px。左右の余白は 20 / 28 / 32px
- 作品グリッド: 600px 未満 1 列、600px 以上 2 列、1000px 以上 3 列。高さは揃えない（縦長・横長をそのまま見せる）
- 1000px 以上では、ヒーローのメインコピーを掛け軸のように**縦書き**で右端に置く。これがこのサイトで唯一の「見せ場」。他は足さない
- セクションの順: ヒーロー → デジタル筆文字について（`digitalIntro`、2〜3文。技法や工程の断定はしない）→ 作品ギャラリー（見出しの下に卒業生への一文 `galleryLead`）→ 先生のごあいさつ（原稿がある時だけ）→ 講座について → フッター。講座への導線は最後に、控えめに

## 作品カード（額装）

- 白いマット（14px の余白）＋ 1px の縁 ＋ やわらかい影。角丸は 2px だけ
- 画像は **切り抜かない**。カード幅に合わせ、縦横比はそのまま。`srcset` で 640px と 1600px を渡し、高密度のスマホでもにじまない
- 「作品ページを見る」「拡大して見る」「Instagram」はタップ領域 44px 以上
- 画像の下に: 作品名（Yuji Syuku 21px）→ 作者名（補助色）→ ひとこと（3 行で省略）→ 「作品ページを見る」「拡大して見る」「Instagram」
- ホバーで 2px 浮く。`prefers-reduced-motion` のときは動かさない

## 作品ページ

- 画像を最も大きく。横幅いっぱい、高さは画面の 82% まで。1000px 以上では右に情報欄（固定）
- 固有の `<title>`、description、canonical、OGP、Twitter カード。OGP 画像は 1200×630 の和紙色キャンバスに作品全体を収める（トリミングしない）
- トップページの OGP 画像は、作者の同意を得た代表作品（`representativeWorkId`）を指定したときだけ出す。未指定なら画像なし
- 「この作品を共有」は Web Share API → 無ければ URL コピー
- 「原寸で開く」で 1600px の画像をそのまま開き、スマホのピンチ操作で細部まで見られる。ライトボックスにも同じリンクと、左右スワイプでの前後移動
- 前後の作品へのリンクと「1 / 30」の位置表示。人気順・いいね・ランキングは置かない

## 画像

- 一覧用 長辺 640px WebP、詳細用 長辺 1600px WebP、OGP 1200×630 JPEG
- 拡大しない。元画像は公開しない。ウォーターマークは付けない
- `width` / `height` を必ず出してガタつきを防ぐ。一覧は `loading="lazy"`、作品ページの主画像は `fetchpriority="high"`
- 透過 PNG は、OGP では和紙色の上に合成される。一覧・作品ページでは白いマットの上に載る

## 動き

- ページ読み込み時のアニメーションは無し。ホバーとダイアログの開閉だけ
- 自動再生・視差・音は入れない

## 書かないこと

- 受講生の本名、作品の技法や制作工程の推測、架空の先生コメント
- 「限定」「残りわずか」などの売り文句
