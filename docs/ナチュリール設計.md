# ナチュリール Q&Aサイト 設計

## 位置づけ
- docs/方針.md の「共通テンプレ」から生成する講座サイトの1つ
- 筆文字Q&Aと同じリポジトリ・同じコードで、設定ファイルの差分だけで
  ビルドする
- 目的は「LINEで来る同じ質問への返信の手間を減らす」こと。機能は盛らない

## 公開範囲
- 公開：トップ／FAQ一覧・詳細／お知らせ（集客ページ兼用）
- 会員のみ：将来の動画・課題・マイページ（初期は非表示）
- 認証は4サイト共通の仕組みを使う。ナチュリールでは初期は
  会員ページを出さない

## ページ構成
1. トップ：講座概要／最新お知らせ3件／FAQ検索窓／「LINEで質問する」ボタン
2. FAQ一覧：カテゴリ別＋キーワード検索
3. FAQ詳細：質問／回答／関連FAQ／「解決しなかった？→LINEで質問」
4. お知らせ：日付順。LINE配信文をそのまま転載できる形
- 質問フォームは作らない。公式LINEへのリンクで代替

## 質問の流れ
1. 受講生がLINEで質問
2. 先生（またはZUMA）がスプレッドシートの faqs に質問・回答を追記
3. サイトがビルド時にスプシから取得して反映
4. 以降は同じ質問に FAQ の URL を返す

## データ（スプレッドシート・4講座共通）
1つのスプシに、講座別シートではなく course 列で区別する。
- faqs: id / course / category / question / answer / status(公開|下書き) / updated
- announcements: id / course / date / title / body / status
- categories: course / category / order
- status が「公開」のものだけサイトに出す
- 各シートは CSV 公開し、ビルド時に fetch する

## 技術構成
- Cloudflare Pages ＋ 静的ビルド（GOMAYAサークルと同じ構成に寄せる）
- データはスプシの公開CSVをビルド時に取得。
  GitHub Actions の定期再ビルド or 手動デプロイで反映
- 講座差分は設定ファイル1つ：講座名／色／ロゴ／公式LINEリンク／course値
- 同一リポジトリで筆文字・ナチュリールを設定違いでビルドできる構造にする
