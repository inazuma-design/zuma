# agents — AI エージェントの置き場所

ZUMA で使う AI エージェントを置くフォルダです。
1 フォルダ = 1 エージェント。会員サイト本体（`src/`）や `fudemoji-sotsugyo/` とは切り離してあり、
ここに何を置いてもサイトの動作やビルドには影響しません。

## いまあるもの

| フォルダ | 状態 |
| --- | --- |
| `agent-01/` | 入れ物だけ。役割は未定（名前も仮） |

## 中身の決まりごと

各エージェントのフォルダには、まず `profile.md` を 1 枚だけ置きます。
「何をする人か」をここに書き、それが決まってから動かす仕組み（プログラムや設定）を同じフォルダに足します。

```
agents/
  agent-01/
    profile.md   ← 役割・仕事・やらないことを書く紙（いまは空欄）
```

## エージェントを増やすとき

1. `agent-01/` をフォルダごとコピーして、名前を付け替える（英小文字とハイフン。例: `line-helper`）
2. `profile.md` の空欄を埋める
3. 上の「いまあるもの」の表に 1 行足す

## 置かないもの

API キーやパスワードなどの秘密の値は、このフォルダに書きません（`.env` などリポジトリに入らない場所へ）。
